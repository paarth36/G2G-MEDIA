# G2G Media Website

A static website project split into HTML, CSS, JavaScript, and assets.

## Run locally
Open `index.html` in a modern browser. For best results, use a local development server such as VS Code Live Server.

## Project structure
- `index.html`: page structure and content
- `css/style.css`: styles, layout, responsive rules, and visual effects
- `js/main.js`: scroll, canvas, and page interactions
- `js/ideas.js`: Unscripted Ideas generator and contact form behavior
- `assets/images/`: logo and image assets
- `assets/videos/`, `assets/icons/`, `assets/fonts/`: folders for future media assets
- `docs/project-notes.md`: maintenance notes

## Brand wording
The website's concept is now **Unscripted Ideas** instead of **Random Ideas**.
